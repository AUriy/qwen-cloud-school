# План обучения: "Курс молодого бойца: Разработка в облаке"

**Философия:** Сквозной проект в изоляции. Навыки работы с Git, агентами и контекстом без риска для основной кодовой базы.

## Урок 1: "Безопасный периметр" (Изоляция и Структура)
- Создание новой ветки `feature/lesson-sandbox` для полной изоляции внутри учебного проекта.
- Инициализация структуры проекта `lesson-project` (папки, базовые конфиги).
- Создание базовых файлов: `README.md`, `project.config.yaml`, `.gitignore`.
- Понимание принципа "песочницы".

## Урок 2: "Первый MVP и Запуск" (Hello World + Fullstack)
- Создание простого `index.html` и серверной части (`server.mjs`).
- Настройка `package.json` и скриптов запуска.
- Запуск сервера в терминале среды.
- Редактирование "на лету": изменение портов, добавление новых эндпоинтов.
- Обработка ошибок на практике.

## Урок 3: "Зависимости и Самописный код" (Node.js и Библиотеки)
- Установка внешних библиотек через `npm install`.
- Подключение самописных библиотек (копирование файлов из основного проекта).
- Использование библиотек в коде.
- Понимание размещения зависимостей в облаке.

## Урок 4: "Машина времени" (Git, Diff, Синхронизация)
- Практика команд `git status`, `git diff`, `git commit`.
- Откат изменений и восстановление после ошибок.
- Синхронизация с локальной машиной: `git pull` и `git push`.
- Работа с конфликтами слияния.

## Урок 5: "Архитектор и Контекст" (Документация и Память Агента)
- Создание папки `AGENTS/` и файла `CONTEXT.md`.
- Описание проекта, целей и правил в текстовых файлах.
- Механизм переноса контекста между проектами через копирование файлов.
- Ролевая модель взаимодействия: архитектор и исполнитель.

## Урок 6: "Мультиагентская работа" (Оркестрация)
- Разделение задач между различными промптами/агентами.
- Проверка соблюдения правил из документации.
- Полный цикл разработки с участием нескольких агентов.

## Финальный экзамен: "Перенос опыта"
- Анализ проделанной работы.
- План переноса практик в основной проект.
- Очистка или архивирование учебной ветки.

## Решения ключевых проблем:
- **Самописные библиотеки:** Копируются в учебный проект как обычные файлы.
- **Передача контекста:** Через файлы документации (`PROJECT_BRIEF.md`, `CONTEXT.md`).
- **Безопасная работа:** Использование изолированных веток без риска для основного кода.
- **Перенос наработок:** Механизм копирования файлов и папок между проектами.
